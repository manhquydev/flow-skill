repo. Root `CLAUDE.md` is a **symlink** to this file. On Windows, if `core.symlinks=false`,
git may materialize a text file whose contents are the target name `AGENTS.md` — still
read **this** file. Do not confuse root `CLAUDE.md` with `skills/flow/law/CLAUDE.md`

[`docs/adr/0001-discipline-layer-identity.md`](docs/adr/0001-discipline-layer-identity.md).

reopening that ADR.

## Layout (pointers)

- `skills/flow/` — installable skill (runner, harness, templates, law, references, eval)
- `npm-wrapper/` — installer CLI; bundled skill tree is generated by `scripts/sync.mjs`
  (gitignored). Parity is tarball `--compare`, not `git diff` of that tree.
- `tests/` — bash suites listed in `tests/manifest.txt`; run via `bash tests/run_all.sh`
- `docs/` — architecture, quality-metrics, release-process, journals, `adr/`
- `website/` — owned by `feat/flow-website`. **Never edit it on this branch.**

## Homeless standing orders

These have no other home. Keep them here only.

1. **Process token.** Every flow byte runs because a hosting agent or the operator invoked
   it, and flow terminates when that returns. Full invariant: the identity ADR.
2. **Eval STOP.** Do not modify the live `_eval_engine_run` body or `_run_with_timeout` in
   `skills/flow/runner/flow.sh`. If a change requires either, stop and report.
3. **Locate by content.** Find code by searching content, not by plan-file line numbers
   (they drift).
4. **No billable live `claude` calls** unless the operator explicitly checkpoints. Replay
   and fixtures are the offline path.
5. **Do not invent a second home** for a fact that already has one.

## Commands (entry only)

Full verb table: `README.md` and `skills/flow/SKILL.md`. Everyday: `/flow` (status),
`/flow next`, `/flow card`, `/flow check C-NNN`, `/flow doctor`. Codex: `$flow`.
Mechanical ground truth is `bash skills/flow/runner/flow.sh <cmd>` (exit 0/1).

## Conventions

- bash 3.2-safe; zero new runtime deps; degrade loudly, never lower a gate.
- Skill product version ≠ npm installer version (`docs/release-process.md`).
- New bash suites: `tests/test_*.sh` **and** a `tests/manifest.txt` row in the same change.
- A wave that adds a gate-enforced rule adds ≥1 hollow/sound eval fixture pair (ADR).
- `docs/doc-budgets.txt` is enforced in preflight/CI; advisory during a `/flow` run.

## Test-evidence protocol

Match evidence to the surface you changed. Do not default to the full 3-OS suite.

| Change | Evidence |
|---|---|
| One bash suite / runner slice | that suite; add `tests/test_manifest_runner.sh` if the registry moved |
| `sync.mjs` / npm-wrapper | `cd npm-wrapper && npm test` |
| Pack / install path | `bash scripts/pack-rehearsal.sh` |
| Docs / budgets | `bash scripts/check-doc-budgets.sh` and `tests/test_doc_budgets.sh` |
| Version / release surface | `bash scripts/check-release-coherence.sh` |
| Cross-cutting runner / harness | `bash tests/run_all.sh` |

CI source of truth is GitHub Actions `bash-suite` (ubuntu/macos/windows) under
`all-checks-passed`. Pushes to research branches do not run GHA
(`on.*.branches: [master]`).
